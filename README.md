# The Little Details

Website for The Little Details Vehicle Enhancements, Unit 2a, 1 Stockton End, Sandy, SG19 1SB.

Facts on the site come from the public Google listing, public Google reviews, and the Companies House record for company 13427456. The site does not invent prices, finance, warranties, or opening hours.

```bash
npm install
npm run build
npm run preview
```

The production build is set up for GitHub Pages at `/TheLittleDetails/`.
